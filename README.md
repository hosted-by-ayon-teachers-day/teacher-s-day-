# Teacher's Day Website — Class IX

Mobile-first static website for GitHub Pages.

## Current images
This package contains 26 teacher artworks from the uploaded ZIP.

## GitHub Pages
1. Upload the contents of this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Open the Pages URL GitHub provides.

## Adding the 27th teacher
Add the final image as `images/teacher-27.png`, then add one object to the `teachers` array in `script.js`.
